Generic status pill (semantic tones) plus a compact numeric `CountBadge`. For pipeline stages and priority use the dedicated StageBadge / PriorityBadge.

```jsx
<Badge tone="success" dot>Activo</Badge>
<Badge tone="warning">Pendiente</Badge>
<CountBadge count={3} />
```

Tones: `neutral` · `primary` · `success` · `warning` · `error` · `info`.
