Pill marking a prospect's pipeline stage, with a colored dot. Labels default to the Spanish stage names.

```jsx
<StageBadge stage="contacted" />
<StageBadge stage="joined" />
<StageBadge stage="evaluating" label="En valoración" />
```

Stages: `new` (Nuevo) · `contacted` (Contactado) · `presented` (Presentación realizada) · `evaluating` (En valoración) · `joined` (Incorporado) · `discarded` (Descartado).
