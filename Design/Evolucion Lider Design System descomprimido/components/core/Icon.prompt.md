Renders a Lucide glyph by kebab-case name. Requires the Lucide UMD script (`https://unpkg.com/lucide@latest`) on the page. Inherits `currentColor`, 2px stroke.

```jsx
<Icon name="phone" size={20} />
<Icon name="message-circle" />
<Icon name="bar-chart-3" color="var(--color-primary-500)" />
```

System icons: home, users, bar-chart-3, phone, message-circle, mail, instagram, plus, square-pen, save, arrow-left, filter, menu, calendar, clock, chevron-right, check, x, user, sticky-note, layers, alert-circle, info, star, trash-2, more-vertical.
